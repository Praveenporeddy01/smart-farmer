# Smart Farmer Assistant 🌾🤖

An interactive Machine Learning web application that predicts the most suitable crops to grow based on environmental and soil metrics (Nitrogen, Phosphorus, Potassium, Temperature, Humidity, pH, and Rainfall).

## 🚀 Tech Stack
* **Backend:** Python, Scikit-Learn (Random Forest Classifier)
* **Frontend Dashboard:** Streamlit
* **Data Source:** Crop Recommendation Dataset

## 🛠️ How to Run Locally
1. Clone the repository
2. Activate your virtual environment
3. Install dependencies: `pip install streamlit scikit-learn pandas`
4. Launch the dashboard: `streamlit run smart_farmer/app.py`
